# Блоксфера 3D

Среда блочного программирования в 3D прямо в браузере. Собирай скрипты из цветных блоков и оживляй объекты на трёхмерной сцене.

**Запуск:** открой `index.html` в Google Chrome (или включи GitHub Pages: Settings → Pages → Branch `main` / root).

## Возможности
- ✨ ИИ-помощник: напиши или скажи голосом (🎤), какую игру хочешь, и он соберёт её из блоков или изменит текущую (можно вернуть как было); ответы читаются вслух (🔊 Озвучка)
- Раздел блоков «ИИ»: персонажи с характером отвечают на вопросы и болтают с игроком
- Стартовый экран для новичков
- Переключатель 3D / 2D: объёмный мир или плоский вид сбоку
- Свой персонаж: кожа, кофта, штаны, причёска, кепка, корона или колпак; сам шагает, прыгает и машет рукой
- Поиск блоков по словам, подсказки и справка «Как пользоваться»
- Камера: сзади, от первого лица, сверху, сбоку; погода: снег, дождь, листопад; мелодии; управление мышкой
- 3D-сцена: куб, шар, цилиндр, конус, пирамида, бублик, капсула, платформа, монета
- Перетаскивание, вращение и масштаб объектов мышкой прямо на сцене
- Физика: гравитация, прыжки, упругость, столкновения, твёрдые и «сквозные» объекты
- Камера, которая следит за игроком, тряска камеры, день / закат / ночь со звёздами, туман
- Копии объектов (клоны), сообщения между объектами, таймеры, касания, клики
- Звук: эффекты, ноты, 4 инструмента, синтез речи
- Следы за объектами, взрывы частиц, надписи на экране, переменные, списки, функции
- Копирование скрипта на другой объект перетаскиванием
- Автосохранение, открытие и копирование проекта
- Пять примеров: «Говорящий робот» (ИИ), «Прыгун 2D», платформер «Монетки», «Солнечная система», «Пианино-кубы»

## ИИ
Внутри Claude ИИ работает через аккаунт Claude без ключа. На сайте (GitHub Pages) нужен ключ Anthropic API: **Проект → Ключ ИИ**. Ключ хранится только в браузере и отправляется только в Anthropic. Используется модель `claude-opus-5-5`.

`anthropic-sdk.mjs` — официальный Anthropic TypeScript SDK 1.8.0, собранный в один файл для браузера (лицензия MIT).

Горячие клавиши: `Ctrl+Enter` — старт, `Esc` — стоп, `Ctrl+Z` — отменить.

Сделано на [Blockly](https://developers.google.com/blockly) и [three.js](https://threejs.org).
